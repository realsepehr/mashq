# مشق‌یار — راهنمای ساخت APK با گیت‌هاب (بدون اندروید استودیو)

## مراحل

### ۱. ساخت ریپازیتوری در گیت‌هاب
1. وارد GitHub بشو و یک ریپازیتوری جدید (Public یا Private) بساز، مثلاً به اسم `mashqyar-app`.
2. تمام فایل‌های این پوشه (`mashqyar-app`) رو داخل اون ریپازیتوری آپلود کن.
   - ساده‌ترین راه: توی صفحه‌ی ریپازیتوری روی "Add file → Upload files" بزن و همه‌ی فایل‌ها/پوشه‌ها رو (با حفظ ساختار `.github/workflows/build-apk.yml` و `www/index.html`) بکش و رها کن.

### ۲. اجرای بیلد
1. بعد از آپلود، به تب **Actions** ریپازیتوری برو.
2. یک Workflow به اسم **Build Android APK** می‌بینی. روش کلیک کن.
3. دکمه‌ی **Run workflow** رو بزن (سمت راست) و تأیید کن.
4. حدود ۳ تا ۶ دقیقه صبر کن تا بیلد کامل بشه (نشانه‌ی سبز رنگ = موفق).

### ۳. دانلود فایل APK
1. روی همون اجرای Workflow که تموم شده کلیک کن.
2. پایین صفحه، بخش **Artifacts** رو پیدا کن.
3. فایل `mashqyar-debug-apk` رو دانلود کن — این یک فایل zip هست که داخلش `app-debug.apk` قرار داره.
4. فایل apk رو به گوشی اندرویدت منتقل کن (از طریق تلگرام به خودت، گوگل درایو، یا کابل).
5. روی گوشی، فایل apk رو باز کن. اگه پیام "نصب از منابع ناشناس" اومد، اجازه بده (چون از گوگل‌پلی نیست).
6. اپ نصب می‌شه و آیکون «مشق‌یار» رو روی گوشیت می‌بینی.

## نکات
- این APK به‌صورت **debug** ساخته می‌شه؛ برای استفاده‌ی شخصی کاملاً کافیه.
- هر بار که فایل `www/index.html` رو عوض کردی و دوباره در گیت‌هاب Push/Upload کردی، Workflow خودش دوباره اجرا می‌شه (یا می‌تونی دستی از تب Actions اجراش کنی) و APK جدید می‌سازه.
- اطلاعات اپ (مشق‌ها، تنظیمات) به‌صورت محلی روی خود گوشی ذخیره می‌شه و نیازی به اینترنت نداره.
